## Descripción

Proyecto desarrollado en Java para una práctica relacionada con un sistema de aeropuerto.

La práctica implementa:

* Clase padre y clases derivadas.
* Herencia mediante `extends` y `super`.
* Polimorfismo mediante métodos sobrescritos con `@Override`.
* Constructores, métodos `set`, `get` y `toString()`.
* Encapsulamiento y abstracción.
* Interfaz gráfica con `JFrame`, `JTabbedPane`, `JPanel`, `JButton`, `JTextField`, `JComboBox`, `JTextArea` y `JOptionPane`.
* Validaciones y manejo de excepciones.

## Estructura de herencia

```text
               Persona
               /     \
          Pasajero   Empleado
                      /     \
                  Piloto   Sobrecargo
```

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en NetBeans.
3. Ejecutar la clase principal.
4. Utilizar la interfaz gráfica para realizar las operaciones y pruebas.
